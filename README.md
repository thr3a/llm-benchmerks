ローカルLLMサーバーの速度ベンチマークツール。プロンプト処理速度(pp)とトークン生成速度(tg)を計測し、CSVに保存する。

## コマンド

```
uv run run-benchmark.py --base-url https://example/v1 --model deep01 --count 3
```

# パターン

### saitama

- 概要
  - 「埼玉県の魅力を1000文字で紹介してください」というプロンプト
- 意図
  - 日本語のトークン生成速度(tg)を測る

### async_retry_comment

- 概要
  - `async_retry_client.txt` のPythonコードに日本語でコードコメントを付けさせる
- 意図
  - コードの生成速度(tg)を測る
  - 一部日本語も含むので実用的

### summarize

- 概要
  - `8700tokens.md`（約8700トークンの長文）を3行に要約させる
- 意図
  - 日本語のプロンプト処理速度(pp)を測る

### 新しいパターンの追加

- `patterns/` に1ファイル追加し、`PATTERN` を定義して `ALL_PATTERNS` に登録するだけで拡張できる

# 参考

claude-opus-5.5による半導体記事の3行要約

- 半導体産業（デバイス・装置・材料メーカ）は営業利益率が20%以上、好況時には30〜60%に達する一方、自動車産業は高級車を除き概ね10%以下にとどまります。この差は個々の企業の違いではなく、産業構造、すなわち生産効率の違いによるものです。
- 半導体の高利益率の源泉は、1000チップ単位の「バッチ生産」、25枚単位の「ロット生産」、同一仕様ウェーハを大量に流す「ライン生産」の組み合わせにあります。チップが個片化される後工程の利益率が低いことや、新幹線（JR東海）・食パンの例も同じ原理で説明できます。
- 利益率向上にはコスト削減より生産効率の改善が本質的です。ただし半導体は固定費型でハイリスク・ハイリターンなため寡占化が進みやすく、変動費型の自動車産業は利益率が低い反面、大赤字にはなりにくいという違いがあります。
